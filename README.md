## Sobre o Projeto

O **Forge Idea** é uma API RESTful desenvolvida com **Spring Boot** para gerenciamento de ideias e usuários. Este projeto representa uma evolução do projeto [Banco de Ideias - JDBC](https://github.com/Mikael-Theovaldo/banco-de-ideias-jdbc), reimplementado utilizando o ecossistema Spring para demonstrar como o framework simplifica o desenvolvimento de aplicações Java empresariais.

Enquanto a versão anterior utilizava JDBC puro para persistência, esta versão aproveita o poder do **Spring Data JPA** para abstrair o acesso ao banco de dados, o **Spring Web** para expor endpoints REST e o **Spring Boot** para configuração automática e produtividade.

A aplicação permite:
*   Cadastrar e gerenciar usuários via API REST.
*   Criar, listar, atualizar e remover ideias.
*   Associar ideias a usuários específicos.
*   Consumir os dados através de requisições HTTP (JSON).
